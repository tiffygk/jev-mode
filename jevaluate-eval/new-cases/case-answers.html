Questions, in order

  1. Does its non-test code call hosted Jev?
  2. What does its code do with the answers?
  3. Who calls it?
  4. What does it do instead?
  5. Claims to be or call Jev?
  6. Does it claim to call Jev?
TypeKindMeansExample
workflowusesIts own code writes questions, sends them to Jev and acts on the answers.A CI step asks whether a pull request touches billing code and adds a required reviewer if so.
demousesShows Jev's answers to people and does nothing else with them.A page where you paste a product review and see Jev's sentiment probabilities as bars.
agent-toolusesHands Jev's answers to an agent, which decides what to do.An editor extension the coding agent calls to ask whether a diff touches auth; it returns the probability.
libraryusesCode others import that writes its own questions, wording or thresholds.A Python package whose `is_spam(text)` builds the Noul question and applies a 0.8 cut-off.
clientusesAn SDK, proxy or gateway that passes the caller's questions through and ships no question wording or defaults.A Go SDK that sends whatever questions the caller supplies.
guideteachesA post, doc, course or skill that teaches building with or using Jev and makes no calls.A blog series with ten rules for Jev questions and sample requests it never sends.
jev-replacementreplacesOffers others Jev-style answers without Jev: a model, weights, engine or API that accepts Jev's request format or returns its typed answers.A small fine-tuned model served locally that accepts Jev's request format.
jev-mention-onlymentionsUses Jev's name or ideas but doesn't call it, teach it, or offer a stand-in for it.A to-do app called "Jev Tasks" whose README says "powered by Jev" and whose code calls a general chat model.

An AI agent is not a background program. An agent-tool hands Jev's answer to an AI model, such as a coding assistant, that decides what to do next. A scheduled job or background worker that applies a rule written in advance is the project's own code, so the project is a workflow. *Example: a nightly job that closes any account Jev scores above 0.9 as spam: workflow.*

A project that ignores Jev's answers keeps its type. Type it by what it was built to do, and give it 1c. *Example: a chat bot built to flag urgent messages asks Jev and never reads the reply: workflow, 1c.*
