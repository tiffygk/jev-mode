> - JevTools is a localhost dashboard and CLI (`server.py`, `jev_demo.py`) that sends two fixed question sets to hosted Jev, one for customer reviews and one for topic classification, plus a pass-through playground for user-written questions.
> - It does call Jev: one `requests.post` in `call_jev` ([`jev_demo.py:657`](https://github.com/RileyCarney/JevTools/blob/7f6907b4614914cb47c8b089252832f1f2da485f/jev_demo.py#L657)) to the OpenRouter Alpha Decisions endpoint or the TypeSafe direct API.
> - Each fixed set goes out as one batched request, the questions use the right primitives over JSON state, and the thresholds and weights sit in code.
>
> **Top fix:** Split `quality_of_feedback` into two questions, one for how detailed the feedback is and one for whether it holds an actionable suggestion; combine in code ([`concepts/how-to-build-with-system-one`](https://docs.typesafe.ai/concepts/how-to-build-with-system-one), "Decompose the questions").
