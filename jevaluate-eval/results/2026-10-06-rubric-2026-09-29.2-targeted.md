## The partly-covered sentence, tuned by quiz

The first draft ("partly covered is a no") marked harmless gaps, such as a closing message with no length cap that never nears the limit. A writer that never saw the rubric wrote 12 invented projects, each with one gap; the owner answered 11 before any model did (key and scenarios kept privately). 4 were held out at random (seed 20261006), 7 used for tuning.

| Wording | Sonnet, tuning | Sol, tuning |
|---|---|---|
| A: "an input the project is built to handle can fall in the uncovered part" | 17/21 | 15/21 |
| B: "an input like those in the README, examples or tests could reach the uncovered part and change what the project does" | 18/21 | 15/21 |
| B plus "A change only in order or display doesn't count." | 21/21 | 21/21 |

The misses were two projects. In one, every grader read a gap the owner had marked met; on review the owner changed that answer (a plant-part Choice whose own test case, "whole plant wilting", fits no option). In the other, Sol counted reordering a queue as changing what the project does, which the added sentence fixes.

Held out, final wording, 3 runs each: Sonnet 12/12, Sol 12/12.

Cost: 45,398 Sonnet tokens (writer included) and 73,735 Sol tokens on the Codex account. No calls used tools.

The sentence was then split into short sentences with the same meaning and rerun: tuning 21/21 on both; held out Sol 12/12, Sonnet 11/12 (one run read a report hidden from the editors' feed but kept in the archive as display only).
